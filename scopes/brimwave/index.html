Brim wave scope

The pink border of the brotoid page's Fig 3 (map), on its own as a wave. Across: the sweep, the angle around from the phase origin. Up: the latitude where det J = 0 (toward 1). B2. The wave is the same for every q; the ring only marks where q is.

Cycles sets how many turns of the sweep fit across the scope. The window is always centred on the origin, so 1 cycle shows ±180° and 2 cycles show ±360°. Each turn is the same wave: it repeats every 360°. Half a turn on, it comes back upside down, with keep and mirror swapped: lat(ψ + 180°) = −lat(ψ) (check C3: the border is a cone). Check C7 tests the stronger fact, that det J itself is odd: det J(−d) = −det J(d), compared by value, because the swap of signs already follows from C3. So the map behind must start where the window starts. When it started half a turn out, it sat upside down against the wave on even cycle counts (caught and fixed 2026-10-23).

The wave's harmonics. Amplitude (bars) does not depend on the origin. Phase (number) does: 0° means the harmonic peaks at the origin. From a seam every phase is ±90°: sines only. The wave crosses zero there, and h1 and h3 rise through it together. From a fold every phase is 0° or 180°: cosines only. There h1 and h3 have opposite signs and pull against each other, so the fold is only a kiss.
